# Pixel Quest — Gaming Hub

Pixel Quest is a responsive gaming website for browsing game recommendations, comparing genres, and suggesting games to try. It uses semantic HTML and an external CSS stylesheet, with JavaScript interaction tasks to be completed as part of the assignment.

## Live website

After publishing with GitHub Pages, replace the placeholder below with your actual live address:

`https://YOUR-GITHUB-USERNAME.github.io/YOUR-REPOSITORY-NAME/`

## Publish with GitHub Pages

1. Create a public GitHub repository for this project.
2. Upload `index.html`, `styles.css`, `script.js`, `controller.svg`, and `README.md` to the top level of the repository.
3. Commit the files to the `main` branch.
4. In the repository, open **Settings → Pages**.
5. Under the build and deployment settings, choose **Deploy from a branch**, select **main** and **/(root)**, then save.
6. Wait for GitHub Pages to publish the site and copy the live address into this README.
7. Open the live site and test the links, image, responsive layout, JavaScript features, and browser console.
